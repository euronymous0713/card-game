# 効果音ファイル配置場所

このフォルダに、以下のWAVファイルを配置してください。

- game-start.wav
- turn-start.wav
- turn-end.wav
- discard.wav
- attack.wav
- heal.wav
- set-trap.wav
- trap.wav
- hate.wav
- special.wav
- defeated.wav
- victory.wav
- defeat.wav

ファイル名が1文字でも違うと再生されません。

例:
public/sounds/attack.wav
public/sounds/trap.wav


## 追加音

- discard.wav：カードを捨てた時に再生されます。
