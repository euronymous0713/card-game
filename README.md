# インターネット世紀末

伏せ・ブラフ・読み合いカードゲーム。SNS炎上をテーマにした2〜4人リアルタイム対戦ゲーム。

Ver 0.2.0 Alpha

---

## ゲーム概要

プレイヤーはSNSの「フォロワー数」を体力として戦い、最後まで生き残ることを目指す。

- **フォロワー数**（初期 10,000）が0になると脱落（オワコン）
- **ヘイト**（0〜3）：ヘイトが3になると次に受けるダメージが**2倍**
- カードは毎ターン手札が4枚になるよう自動補充される
- 伏せカード（罠）は場に最大2枚まで置ける

### カード種別

| 種別 | 説明 |
|---|---|
| 攻撃 | 対象のフォロワーを減らす |
| 防御/補助 | 自分のフォロワーを回復する |
| 妨害 | 対象のヘイトを上げる |
| 罠 | 伏せて置き、条件を満たしたときに発動する |
| 特殊 | 凍結・炎上・手札破壊など多様な効果 |

### 罠の発動条件

| 条件 | タイミング |
|---|---|
| `onDamage` | ダメージを受けたとき |
| `onHateChange` | ヘイトを変動させられたとき |
| `onTrapEffect` | 罠カードの効果を受けたとき |

### レアリティ

| レアリティ | 出現率 |
|---|---|
| C（コモン） | 55% |
| UC（アンコモン） | 25% |
| R（レア） | 13% |
| SR（スーパーレア） | 5% |
| UR（ウルトラレア） | 2% |

## セットアップ

Node.js が必要です。

```bash
# 依存パッケージをインストール
npm install

# サーバーを起動
node server.js
```

起動後、ブラウザで `http://localhost:3000` にアクセスする。

## 開発者向け情報

### デバッグパネル

URLに `?dev=1` を付けると開発用パネルが表示される。

- プレイヤーのフォロワー数・ヘイトを直接変更
- 任意のカードを手札に追加
- 手札・伏せカードのリセット

### ファイル構成

```
server.js          ← サーバー（ゲームロジック全体）
data/cards.js      ← カードマスターデータ（50枚）
public/
  index.html       ← クライアント（SPA）
  js/main.js       ← クライアントのUI処理・通信
  js/soundManager.js  ← 効果音管理
  js/trapCutin.js     ← 罠発動カットイン演出
  js/dev.js           ← デバッグパネル
  css/             ← スタイル（共通 / PC / モバイル）
  sounds/          ← WAV効果音ファイル
```
